## Description

*KDP accepts a limited set of HTML here: `<b> <i> <br> <p> <ul> <li> <h4>`. The first ~200
characters are all that shows on a phone before "Read more", so the hook must land early.*

```html
<b>Most JavaScript books teach you the language. This one teaches you programming — using JavaScript to do it.</b>

<p>Whether you have never written a line of code or you have been shipping for years, this book meets you where you are and takes you further. It starts at the very beginning — what a variable is, why a semicolon matters — and does not stop until you have worked through the ideas that experienced developers still reach for.</p>

<p>Nothing is assumed. Every concept is defined before it is used, explained in plain English, and shown in code you can run. The style is deliberately conversational and deliberately repetitive: hard ideas come back a second and third time, from a different angle, until they stick.</p>

<h4>What is inside</h4>

<p>Twenty-five chapters, over 200,000 words, and more than 750 pages covering:</p>

<ul>
<li>The foundations — variables, constants, data types, strings, arrays and data structures</li>
<li>Control flow, functions, and regular expressions</li>
<li>Object Oriented Programming, prototypes, classes and design patterns</li>
<li>The DOM, events, forms, the canvas, images and file management</li>
<li>Cookies, storage and databases, dates and time, templating</li>
<li>APIs, AJAX and fetch — talking to other computers</li>
<li>Error handling, debugging and testing, including the browser developer tools</li>
</ul>

<h4>Built for learning, not just reading</h4>

<ul>
<li><b>565 questions and answers</b> — a quiz at the end of every single chapter, each one carrying a clue so you can reason it out</li>
<li><b>32 diagrams</b> drawn to explain the ideas that words alone struggle with</li>
<li><b>Hundreds of runnable code examples</b>, written the long way on purpose — one step per line, with comments explaining not just what each line does but why it is there</li>
</ul>

<h4>Vanilla JavaScript, on purpose</h4>

<p>No React. No frameworks. No build tools to install before you can print "Hello world". Frameworks change every few years; the fundamentals underneath them do not. Learn those first and every framework you meet afterwards becomes easier — because you will recognise what it is doing for you.</p>

<p>Clear. Practical. Complete. This is the JavaScript book you will keep coming back to.</p>
```

## 7 keywords

KDP indexes your title and subtitle already, so these deliberately reach for phrases the
title does not contain.

| # | Keyword phrase | Why |
|---|---|---|
| 1 | `vanilla javascript no frameworks` | Genuinely differentiating and genuinely true of the book |
| 2 | `learn to code from scratch beginner` | Highest-volume buyer intent for the audience |
| 3 | `web development book for beginners` | Category-level intent |
| 4 | `front end developer guide` | Job-title intent — people buy toward a role |
| 5 | `self taught programmer reference` | The reader who keeps it on the desk |
| 6 | `programming fundamentals explained simply` | Matches the book's actual promise |
| 7 | `coding practice questions and answers` | The 559 Q&As, which competitors rarely have |

## Price

The 70% royalty band is **$2.99–$9.99**; above it you drop to 35%. For a 778-page technical
book **$9.99** is the natural pick — top of the band, still an easy purchase against
O'Reilly-priced competition, and roughly triple the royalty of pricing it at $10.99.
